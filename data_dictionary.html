Public reference

Know what each artifact can—and cannot—tell you.

Use this dictionary before interpreting labels, counts, timestamps, or rows. Public fields describe a limited research surface, not financial significance.

Research / monitoring only

Artifacts are not trading signals. They provide no financial advice, no buy/sell/hold recommendation, and no automated execution. Human review is required.

The public snapshot can be stale or incomplete.

Artifact map

Eight public data artifacts

HTML and CSS provide presentation; these CSV and JSON files provide the constrained data surface.

CSV

daily_ai_summary.csv

For: daily public monitoring context and status fields.

Not: a daily instruction, market forecast, or freshness guarantee.

CSV

unified_candidates.csv

For: categorical candidate observations and public state labels.

Not: a ranking, recommendation, or list of opportunities.

CSV

signal_outcomes_history.csv

For: bounded historical tracking and outcome context.

Not: proof of repeatability, future performance, or predictive certainty.

JSON

public_manifest.json

For: named artifact mappings and generation metadata.

Not: proof that underlying observations are semantically current.

JSON

For: availability, row counts, public pair count, score count, exposure mode, and generated time.

Not: a performance scorecard or authorization to act.

JSON

Not: the homepage or dashboard system-summary source.

JSON

For: constrained public status and launch-readiness context.

Not: publication authority or a live service guarantee.

JSON

For: bounded technical-health context intended for public review.

Not: complete internal observability or assurance of correctness.

Field language

Common terms

Generated timestamp
When the artifact reports it was generated; not guaranteed semantic freshness.
Available
The required public structure can be consumed; not a quality judgment.
Rows
A count of records represented by the system summary; not breadth, quality, or opportunity.
Public pair symbols
A constrained count of publicly exposed pair identifiers, often zero by design.
Score count
A count in the summary score object; not an investment score.
Exposure mode
A public-surface control label, not a market regime.

Human review

Interpret, challenge, corroborate.

Human review means checking artifact identity, timestamp, field definition, missing context, source recency, and limitations before drawing even a research conclusion. It does not mean manually converting a label into an action.

Known public-field limits

Categories compress context.

Public fields may omit precision, methodology, internal review notes, private sources, intermediate calculations, and uncertainty detail. Empty, missing, stale, or unavailable values must remain unresolved—not inferred.
