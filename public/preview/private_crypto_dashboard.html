  • Reasoning column (today's flips only): each headline's relevance (Direct match / Market context / Unrelated) and freshness (Today / Recent / Old / Unknown) are computed by lightweight text heuristics, not verified fact-checking.   • Crypto market cap rank: missing, blank, zero, or non-numeric values are shown as "—" and always sort to the end of the "Mkt cap rank" column regardless of sort direction; no fake rank number is ever displayed.
  • Current color age: counts consecutive daily candles (the scanner's "1d" interval) holding the asset's current Blue/Gray/Gold state, shown as days elapsed since it last changed ("New today" = changed on the most recent candle). "Unknown" means the scanner had too few candles to determine a color at all — never guessed. Sorts numerically; "Unknown" always sorts to the end, same rule as market cap rank.
  • Priority score (today's flips only): a 0–100 value that orders flipped assets for review convenience, computed from existing local scanner and reasoning outputs only — flip transition (direction-agnostic; a full Blue↔Gold reversal scores higher than a partial move through Gray), market-cap rank (missing/blank/zero scores 0), current color age, Strong/Medium/Weak reasoning quality, freshest coin-specific headline, and score tier — with component weights that sum to 100. It ranks nothing as better or worse as an asset, implies no bullish/bearish direction, and is not a recommendation, rating, signal, or instruction to act. "High / Medium / Low priority" refers only to suggested review order (thresholds: High ≥ 70, Medium ≥ 45). The flips table is sorted by it by default; every other column still sorts on click.
  • Peg/stable pairs are excluded from flip review. Stablecoin-vs-stablecoin and same-currency USD-pegged pairs (for example USDS/USDT, USDC/USDT, DAI/USDT) are left out of Today's flips, the priority ranking, the quick-chart flip buttons, the flip-transition summary, and the confirmed-flip count shown for review. A CTO color change on a same-currency pegged pair almost always reflects peg deviation, bid/ask spread, or thin-liquidity microstructure — not a directional trend in the underlying asset — so counting it as a meaningful flip would be misleading. Membership is an explicit reviewed asset-code list, not a substring match on “USD”, so genuine fiat pairs such as GBP/USDT are unaffected. These pairs stay visible in the full crypto table above (flagged as an excluded peg pair) and are never removed from the raw scanner output.
  • Watchlist and saved filters are local-browser-only. The ☆/★ Watch toggle (both tables) and the filter bar's saved state (search, flips-only, hide-D-Ignore, watchlist-only, state, tier, priority, reasoning quality) persist to this browser's localStorage only — no login, no account, no server-side storage, nothing synced across devices. A symbol is watched by ticker only: if a ticker is ever delisted and later reused for a different asset, a stale local entry could point at the wrong one. The watchlist stores a symbol and an optional free-text note only — never a quantity, price, cost basis, PnL, or portfolio value. If browser storage is unavailable (e.g. private browsing), the page and its filters still work normally within that view; nothing simply persists across a reload.
